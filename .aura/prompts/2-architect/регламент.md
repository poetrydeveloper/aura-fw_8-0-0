Писать код строго по инструкциям ниже [local].1. 🔡 ПРАВИЛО РЕГИСТРА ПЕРЕМЕННЫХ (CASE SENSITIVITY)Транслятор генерирует имена переменных внутри TypeScript-циклов на основе массива Query(components = [...]) по правилу camelCase (первая буква строчная, префикс Component стирается) [local].Пример: CFrameComponent превращается в cFrame, WeaponStateComponent превращается в weaponState [local].Запрещено: Писать внутри гвардов или формул переменные полностью маленькими буквами (например, cframe или weaponstate) [local]. Компилятор упадет с ошибкой Cannot find name [TS-Weaver-Error].Канон:juliaQuery(components = ["CFrameComponent"]) do
    Guard(condition = "cFrame.value.Position.X > 0") # 'cFrame' строго с большой 'F'!
end
Используйте код с осторожностью.2. 🧮 ТИПИЗАЦИЯ CFRAME И VECTOR3 (МАТЕМАТИКА ДВИЖКА)В экосистеме roblox-ts нативные типы Roblox (CFrame, Vector3) имеют строгую геометрию свойств [local].Запрещено: Писать математические операции сравнения (<, >, <=, >=), если цепочка свойств возвращает тип any [TS-Weaver-Error]. Линтер заблокирует сборку с ошибкой Relation operators can only be used on number or string types! [TS-Weaver-Error].Канон: Обращение к координатам выполнять строго через свойства .Position.X, .Position.Y, .Position.Z или свойство длины вектора .Magnitude [local].3. 📦 СТРУКТУРА МАКРОСА MUTATE (КОНТРАКТ СЛОВАРЯ DICT)Посимвольный токенайзер Ткача изолирует тело мутации строго по первой парной закрывающей скобке словаря Dict(...) [stem-calculative-problem-solving].Запрещено: Передавать внешние Luau-параметры (например, targetEntity = "id") ПОСЛЕ или ВНЕ закрывающей скобки словаря Dict [stem-calculative-problem-solving]. Это приводит к пролазанию знаков = и висячих круглых скобок в TypeScript-объекты [TS-Weaver-Error].Запрещено: Использовать стрелочки вида ->. Разрешены строго стрелочки Джулии => [local].Канон: Все изменяемые поля и свойства цели должны находиться строго внутри круглых скобок Dict(...) через запятую [local]:juliaMutate(component = "WeaponStateComponent", values = Dict("nextTimer" => "0", "isCharging" => "false"))
Используйте код с осторожностью.4. 🚷 ЗАПРЕТ НА ИСПОЛЬЗОВАНИЕ ФИГУРНЫХ СКОБОК {}Исходные файлы ракушек (.jl) являются бесскобочной ДНК игры [local].Запрещено: Самовольно писать фигурные скобки {} внутри кода Джулии для очерчивания блоков логики или циклов [local]. Балансировщик Ткача braceBalance сойдет со счета, нарушит иерархию методов и выдаст ошибку Unexpected end of JSON input или Assertion Failed [TS-Weaver-Error].Канон: Блоки открываются ключевыми словами макросов (Query(...) do, if ...) и закрываются исключительно изолированным словом end на отдельной строке [local].5. 🏹 ТИПИЗАЦИЯ КОМПОНЕНТА УРОНА (DAMAGECOMPONENT ALIAS)Поскольку в физическом паспорте компонентов components.types.ts тип урона выводится динамически, Ткач страхует линтер встроенным алиасом-заплаткой DamageComponent [local].Канон: Внутри ракушек Джулии при расчете урона или коллизий ИИ обязан обращаться к полю value компонента урона: damage.value [local]. Поле защищено на уровне компилятора под типы number (числа) и string (динамические формулы/строки) [local].
