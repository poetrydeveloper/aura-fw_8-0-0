Все ИИ-Агенты (Архитектор и ИИ-Исполнитель) обязаны беспрекословно соблюдать данный синтаксический и топологический контракт. Любое отклонение аннулирует деплой.📂 1. Локация и Именования файлов на хосте WindowsВсе ракушки обязаны физически сохраняться строго в директорию:📂 .aura/services/shells/immutable/Расширение файлов должно быть строго .jl (Чистая Джулия). Имена файлов обязаны строго совпадать с именем класса системы:MovementSystem.jlInputSystem.jlCollisionSystem.jlCleanerSystem.jlWeaponTimerSystem.jlcomponents.types.jl⚠️ 2. Жесткие табу и Запреты (Аппаратный канон)Категорический запрет на TypeScript/TSX обертку: В файлах не должно быть строк import, export const, AuraShell({ или фигурных скобок {} для описания структуры [local].Категорический запрет на JSX-теги: Запрещено писать теги вида <Query>, <Guard>, <Safety> [local].Запрет на коллизии id и className: Запрещено копировать шапки файлов без изменения. У каждого файла обязан быть свой уникальный id и свой className [local].📝 3. Контракт Синтаксиса JuliaМанифест оформляется как чистая функция-конструктор Julia AuraShell(...) или AuraComponentPassport(...), где блоки свойств разделяются запятыми, а внутреннее мясо логики закрывается ключевым словом end [local].Шаблон Спецификации для СИСТЕМ ЛОГИКИ (.jl):juliaAuraShell(
    id = "УНИКАЛЬНЫЙ_ИДЕНТИФИКАТОР_СИСТЕМЫ",
    status = "active",
    version = 1,
    vocabularyContract = "Aura_Galaxy_Vocabulary_v7.0",
    
    # 1. СТРОГИЙ БЛОК МЕТАДАННЫХ (Ищется в шапке манифеста)
    meta = Dict(
        "executionSide" => "Server_ИЛИ_Client",
        "flameworkPattern" => "MatterSystem_ИЛИ_ControllerMethod",
        "className" => "ТОЧНОЕ_ИМЯ_КЛАССА_СИСТЕМЫ",
        "methodName" => "ТОЧНОЕ_ИМЯ_МЕТОДА_КЛАССА",
        "context" => "Текстовое описание задачи для ИИ-Архитектора"
    ),
    
    # 2. СЕМАНТИЧЕСКИЕ ПЕРСПЕКТИВЫ ДАННЫХ
    perspectives = Dict(
        "semanticSvo" => Dict("subject" => "ИмяСистемы", "action" => "Глагол", "object" => "Компонент"),
        "dataFlow" => Dict("reads" => ["Массив", "Компонентов"], "mutates" => ["Массив", "Мутаций"])
    ),
    
    # 3. МЯСО ЛOГИКИ (Функциональный блок)
    render = function(ctx)
        # Циклы Query оформляются строго через do ... end
        Query(components = ["Список", "Компонентов"]) do
            Safety(limit = 1000);
            Guard(condition = "Условие_TypeScript_Строкой");
            Calculate(var = "ИмяПеременной", expr = "Выражение_Строкой");
            Mutate(component = "ИмяКомпонента", values = Dict("поле" => "значение"));
            
            # Вложенные циклы
            NestedQuery(target = "АРХЕТИП_ЦЕЛИ") do
                # Любой чистый Luau-код Roblox вставляется текстом напрямую:
                ctx.world.despawn(entityId)
                print("Событие обработано!")
            end
        end
    end
)
Используйте код с осторожностью.Шаблон Спецификации для ПАСПОРТА КОМПОНЕНТОВ (components.types.jl):juliaAuraComponentPassport(

Правила оформления атомарных макросов:Каждая строка Guard, Safety, Calculate, Mutate обязана заканчиваться точкой с запятой ; [local].Условия внутри Guard(condition = "...") и выражения внутри Calculate(expr = "...") пишутся как чистый TypeScript-код, обёрнутый в двойные кавычки [local].Ключевое слово end используется строго для закрытия функционального блока render = function(ctx), циклов Query() do и NestedQuery() do [local].
