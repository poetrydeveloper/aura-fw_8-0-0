СТРАНИЦА 2. ПЯТЬ ВЕЛИКИХ МАКРOСOВ УПРАВЛЕНИЯ ВНУТРИ RENDER = FUNCTION(CTX)

ЖЕСТКИЙ ЗАКОН ТОКЕНАЙЗЕРА: Абсолютно все макросы внутри тела функции render обязаны записываться строго в одну физическую строку. Любой перенос строки внутри макроса, аргумента или словаря ломает посимвольный парсер ядра Ткача и бракуется на входе. На конце каждого плоского макроса обязана стоять точка с запятой ;.

1. Макрос Query (Корневой ECS-итератор)

Открывает блок верхнего уровня для перебора сущностей, содержащих указанные компоненты. Требует закрытия через end.

Query(components = ["ArchetypeComponent", "CFrameComponent"]) do

2. Макрос Safety (Предохранитель итераций)

Обязан идти самой первой строкой сразу после открытия любого do-блока цикла. Ограничивает лимит перебора для предотвращения краша сервера.

    Safety(limit = 1000);

3. Макрос Guard (Ранний возврат / Прерывание)

Разворачивается транслятором в конструкцию if (!(condition)) continue;. Служит для фильтрации сущностей. Текст условия обязан быть валидным JS-выражением в одну строку.

    Guard(condition = "archetype.type === 'PLAYER'");

4. Макрос Calculate (Локальное вычисление)

Объявляет во внутреннем скоупе цикла неизменяемую TypeScript-константу const имя = выражение; для математических расчетов.

    Calculate(var = "playerPos", expr = "cFrame.value.Position");

5. Макрос Mutate (Атомарное изменение компонента)

Единственный легальный способ изменить данные компонента в ОЗУ игрового мира Matter ECS. Изменяемые поля передаются плоским словарем в одну строчку.

    Mutate(component = "VelocityComponent", values = Dict("value" => "targetVelocity", "targetEntityId" => "targetEntityId"));

6. Макрос NestedQuery (Вложенный ECS-итератор целей)

Используется внутри корневого Query для организации поиска связей (выбор цели ИИ, просчет коллизий). Нативно разворачивает переменные целевой сущности с префиксом target (например, targetCFrame). Требует закрытия через end.

    NestedQuery(target = "ENEMY_INTERCEPTOR") do
