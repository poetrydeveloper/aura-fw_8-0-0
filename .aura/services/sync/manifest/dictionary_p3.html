СТРАНИЦА 3. РАЗРЕШЕННЫЙ БЕЛЫЙ СПИСОК (ALLOWED WHITE LIST) ROBLOX API И МАТЕМАТИКИ

Внутри строк макросов Calculate(expr = "...") и Guard(condition = "...") ИИ-Исполнителю разрешено использовать строго фиксированный набор методов и свойств. Любой вызов вне этого списка блокируется лексическим валидатором на хосте.

1. Геометрия пространственных матриц (CFrame Класс Roblox)

Разрешенный терм Тип возврата Контекст применения и пример использования
.value CFrame / Vector3 Извлечение чистого Luau-значения из контейнера ECS-компонента Аура-8.
.Position Vector3 Извлечение трехмерного вектора позиции из CFrame. Пример: cFrame.value.Position
.LookVector Vector3 Извлечение единичного вектора направления взгляда матрицы. Пример: cFrame.value.LookVector

2. Трехмерные векторы (Vector3 Класс Roblox)

Разрешенный терм Тип возврата Контекст применения и пример использования
Vector3.new(x, y, z) Vector3 Конструктор создания нового вектора. Пример: new Vector3(0, 25, 0) (Ткач сделает автовыравнивание под TS).
.X, .Y, .Z Number Чтение отдельных физических осей координат. Пример: math.abs(cFrame.value.Position.X)
.Magnitude Number Скалярная длина вектора (расстояние). Пример: playerPos.sub(enemyPos).Magnitude
.Unit Vector3 Нормализованный единичный вектор направления. Пример: direction.Unit

3. Библиотека Math, Системные функции и Среда Мира

    # Только эти встроенные математические методы Luau / TS гарантированно скомпилируются:
    - math.abs(val)      # Модуль числа (абсолютное значение осей X/Y/Z)
    - math.min(a, b)     # Выбор минимального значения (лимитеры скоростей)
    - math.max(a, b)     # Выбор максимального значения (лимитеры кулдаунов орудий)
    - math.sin(angle)    # Тригонометрический синус (траектории волн ИИ)
    - math.cos(angle)    # Тригонометрический косинус
    - tick()             # Текущее unix-время сервера (для дельт таймеров оружия)
    - print(...)         # Отладка в Output Roblox Studio
    - ctx.world.spawn()  # Создание чистой сущности (для спавнера волн ИИ)
    - ctx.world.despawn()# Физическое удаление сущности из ОЗУ сервера (для сборщика мусора Debris)
