СТРАНИЦА 1. КАНOН ВНЕШНЕЙ СТРУКТУРЫ И СЕМАНТИЧЕСКИХ МЕТАДАННЫХ v38.9.100

Каждая ракушка Аура-8 обязана инициализироваться строго через вызов конструктора AuraShell(...). Использование любого глобального кода вне тела конструктора или объявление кастомных функций верхнего уровня категорически запрещено.

1. Жесткая схема обязательных корневых атрибутов:

Атрибут Тип данных Валидация / Ограничение
id String (Кавычки) Уникальный алфавитно-цифровой идентификатор ракушки в нижнем регистре через подчеркивание.
status String (Кавычки) Строго фиксированное значение: "active".
version Number (Целое) Целое положительное число (инкремент версии графа).
vocabularyContract String (Кавычки) Строго фиксированное значение: "Aura_Galaxy_Vocabulary_v7.0".

2. Жесткая схема словаря meta = Dict(...)

Содержит технический паспорт для генератора Ткача. Любые кастомные ключи приводят к отторжению файла валидатором.

  • "executionSide": Допустимые значения только "Server", "Client" или "Shared".
  • "flameworkPattern": Допустимые значения только "MatterSystem" (для логики) или "GlobalConstants" (для реестров).
  • "className": Строго совпадает с физическим именем файла на хосте Windows (без расширения .jl).
  • "methodName": Имя исполняемого метода (обычно совпадает с задачей системы).
  • "context": Краткое текстовое описание задачи. Запрещено использовать внутри строки латинские буквы e-n-d подряд!

3. Жесткая схема словаря perspectives = Dict(...)

Описывает граф семантических связей субъект-действие-объект (SVO) и dataflow для Memgraph СУБД [1, 2].

    perspectives = Dict(
        "semanticSvo" => Dict("subject" => "ИмяСистемы", "action" => "Mutates|Triggers|Defines", "object" => "ИмяКомпонента"),
        "dataFlow" => Dict("reads" => ["МассивКомпонентов"], "mutates" => ["МассивКомпонентов"])
    )
